# ZombieMutex — Project Discussions

Public conversation threads for the projects and experiments on [ZombieMutex](https://zombiemutex.com/projects).

Each project has its own GitHub Discussion. Ask about the implementation, share a minimal reproduction, suggest a fix, or compare results.

**Please don't post credentials, private customer data, proprietary source code, restricted material, or identifying information about other people.** Technical examples should use synthetic inputs.

This repository contains no private website source or unpublished customer projects. Comments are public and GitHub sign-in is required to post. GitHub's moderation controls apply.
